# Data governance and public-release policy

This GitHub repository was found to be **public** at integration time. Only methodological text, empty schemas and scripts using synthetic test fixtures may be committed until a release and copyright review is completed.

Do **not** publish:
- Licensed original Web of Science full metadata exports, bibliographic datasets with redistribution restrictions, or copyrighted primary PDFs;
- reviewer-identifying or unpublished independent human assessment workbooks without approval;
- private authentication material, secrets or sensitive research data;
- unpublished manuscript, figures, full extracted evidence, or raw screening registers without explicit scientific/publication clearance.

To make a reproducibility package publicly useful without source redistribution, publish code, provenance schema, search syntax when cleared, carefully scoped derived aggregate data, source identifiers permitted by license and instructions for licensed source retrieval. Preserve provenance hashes and keep restricted underlying sources in secure storage. An archived release DOI must wait for evidence and rights review.

The data dictionary and validator are analytical infrastructure, **not proof of independent review completion or research replicability**.
